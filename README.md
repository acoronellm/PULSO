# Pulso

## Resumen ejecutivo

Las enfermedades cardiovasculares representan una de las principales causas de mortalidad a nivel mundial, lo que convierte la identificación temprana de factores de riesgo en una necesidad relevante para la prevención y la educación en salud. En este contexto surge PULSO (Plataforma Inteligente para la Predicción Explicable y Simulación Personalizada del Riesgo Cardiovascular mediante Machine Learning y Aprendizaje Continuo), como una propuesta orientada a utilizar técnicas de inteligencia artificial para apoyar la evaluación del riesgo cardiovascular dentro del sistema médico. El proyecto se plantea como un MVP (Producto Mínimo Viable) que busca validar las funcionalidades principales de la solución.

El proyecto busca solucionar la dificultad de obtener una evaluación del riesgo que no solo proporcione una predicción, sino que también permita comprender los factores que influyen en ella y explorar cómo determinados cambios podrían modificar el resultado. Para esto, PULSO propone una plataforma web capaz de estimar el riesgo cardiovascular de una persona mediante modelos de Machine Learning entrenados con datos clínicos públicos. Además, incorporará mecanismos de explicabilidad para identificar los factores que más contribuyen a cada predicción, simulación de escenarios personalizados para observar el efecto de modificar variables como el peso, la presión arterial, el colesterol o la actividad física, y generación de recomendaciones preventivas enfocadas en factores modificables.

El alcance contempla el diseño e implementación de una plataforma web con una base de datos para gestionar la información, una API para integrar sus diferentes servicios, mecanismos básicos de actualización del modelo predictivo y un proceso de validación experimental para evaluar su desempeño. También se plantea la comparación de diferentes modelos de Machine Learning y la incorporación de herramientas de explicabilidad tanto individual como global.

El principal valor de PULSO radica en integrar predicción, explicabilidad y simulación en una misma herramienta. De esta manera, el sistema no se limita a indicar un nivel de riesgo, sino que busca ayudar al usuario a comprender qué factores están relacionados con su resultado y qué cambios en factores modificables podrían influir en él. Así, la plataforma se plantea como una herramienta de apoyo a la toma de decisiones dentro del sistema médico, orientada principalmente a la prevención y educación en salud cardiovascular.
