# Pulso

## Resumen ejecutivo

Las enfermedades cardiovasculares representan una de las principales causas de mortalidad a nivel mundial, lo que convierte la identificación temprana de factores de riesgo en una necesidad relevante para la prevención y la educación en salud. En este contexto surge *PULSO (Plataforma Inteligente para la Predicción Explicable y Simulación Personalizada del Riesgo Cardiovascular mediante Machine Learning y Aprendizaje Continuo), como una propuesta orientada a utilizar técnicas de inteligencia artificial para apoyar la evaluación y prevención del riesgo cardiovascular. El proyecto se plantea como un **MVP (Producto Mínimo Viable)* dirigido principalmente a personas no especializadas, con el propósito de brindarles información comprensible sobre su estado de riesgo cardiovascular.

El proyecto busca solucionar la dificultad de obtener una evaluación del riesgo que no solo proporcione una predicción, sino que también permita comprender los factores que influyen en ella y explorar cómo determinados cambios podrían modificar el resultado. Para esto, PULSO propone una plataforma web capaz de estimar el riesgo cardiovascular de una persona mediante modelos de Machine Learning entrenados con datos clínicos públicos. Además, incorporará mecanismos de explicabilidad para identificar los factores que más contribuyen a cada predicción, el análisis de diferentes conjuntos de datos para identificar posibles riesgos asociados a distintas enfermedades cardiovasculares, y la simulación de escenarios personalizados para observar el efecto de modificar variables como el peso, la presión arterial, el colesterol o la actividad física.

El alcance contempla el diseño e implementación de una plataforma web con una base de datos para gestionar la información, una API para integrar sus diferentes servicios, mecanismos básicos de actualización de los modelos predictivos y un proceso de validación experimental para evaluar su desempeño. También se plantea la comparación de diferentes modelos de Machine Learning y la incorporación de herramientas de explicabilidad tanto individual como global. Adicionalmente, se implementará un sistema basado en *RAG (Retrieval-Augmented Generation)* que utilizará guías clínicas y fuentes médicas confiables para generar respuestas y recomendaciones relacionadas con los resultados obtenidos, utilizando un lenguaje sencillo y comprensible para personas no especializadas.

El principal valor de PULSO radica en integrar predicción, explicabilidad, identificación de posibles riesgos y simulación en una misma herramienta, acompañadas de información médica presentada de manera accesible. De esta manera, el sistema no se limita a indicar un nivel de riesgo, sino que busca ayudar al usuario a comprender qué factores están relacionados con su resultado, qué posibles riesgos puede presentar y cómo determinados cambios en factores modificables podrían influir en él. Así, la plataforma se plantea como una herramienta de apoyo para la *prevención y educación en salud cardiovascular*, proporcionando información que facilite al usuario la comprensión de su situación y la toma de decisiones relacionadas con su salud.
